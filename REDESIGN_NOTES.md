# Deepentra Academy — Public Website Redesign

This version keeps the existing React/Tailwind architecture and focuses on the public academy experience.

## Product direction
- Public site only: discovery, trust, program selection, workshops, and institutional enquiries.
- Core message: **Learn AI. Build real things. Prove what you can do.**
- Three tracks: AI Literacy, Applied AI, and AI & Software Careers.
- Outcome-first copy instead of long tool lists and generic marketing language.
- Public pages avoid pretending that mock learner data, scores, partners, or outcomes are real.

## Visual direction
- Dark-first, premium AI/engineering aesthetic with restrained indigo/violet/cyan accents.
- Technical grid and controlled radial glows instead of generic stock imagery.
- Plus Jakarta Sans for interface/headings and JetBrains Mono for technical labels.
- Consistent premium cards with subtle borders, restrained shadows, and compact spacing.
- Stronger hierarchy: outcome → audience → build → skills → curriculum → evaluation → CTA.
- Responsive and reduced-motion friendly.

## Navigation
Primary: Programs, Workshops, For Institutions, About, Explore Programs.
Secondary/utility pages remain reachable through the footer and direct URLs where appropriate.

## Content rules
- Prefer concrete outcomes over claims.
- Prefer examples of builds over lists of technologies.
- Avoid fake statistics, fake testimonials, fake partner logos, employment guarantees, or unsupported performance numbers.
- Keep technical language when it helps a learner understand what they will actually build.

## Run locally
```bash
npm install
npm run dev
```
